# История изменений

<p align="center"><a href="CHANGELOG.md">English</a> · <b>Русский</b></p>

Заметные изменения Draftsman. Версии нумеруются по [семантическому версионированию](https://semver.org/lang/ru/).

## [1.2.1] — 2026-11-14
### Изменено
- Подсвеченные провода: маркеры в середине провода (точки, которые добавляют рероут) и точки рероутов принимают цвет
  подсветки. ComfyUI рисует маркеры на подсвеченном проводе белыми, а яркая линия закрывала только их середину.

### Документация
- README: анимации подсвеченных проводов и комет — выделенная нода, провода через рероуты, наведение на слот.
- Русский README приведён в соответствие с английским: картинки, подробности о цветах, Nodes 2.0, подсказки настроек.

## [1.2.0] — 2026-11-12
### Добавлено
- **Форма группы ▸** в меню группы: прямые (стандартно), скруглённые углы или карточка; сохраняется в workflow
  и отменяется Ctrl+Z.
- **Кнопка сворачивания ноды:** точка в шапке ноды рисуется кнопкой — шеврон на тёмной подложке (по умолчанию),
  плюс / минус или стандартная точка (Settings → Draftsman → Ноды).
- Значок циркуля в заголовке меню Draftsman и значок раздела настроек Draftsman.

### Изменено
- Блок Draftsman в контекстном меню не разрывается, когда другие расширения добавляют свои пункты в то же меню.
- Пункты меню группы переименованы: «Раскрасить рамку группы…» и «Раскрасить ноды группы…».

## [1.1.0] — 2026-11-04
### Добавлено
- **Выделение проводов:** провода выделенных нод рисуются ярко и поверх остальных, остальные приглушаются; входящие
  голубые, исходящие оранжевые; при наведении на вход или выход выделяются только его провода
  (Settings → Draftsman → Провода).
- **Кометы:** по каждому подсвеченному проводу от выхода ко входу летит яркая голова с затухающим хвостом, в том числе
  через рероуты; рисуются на отдельном слое с частотой экрана.
- **Стилизованные подсказки выходов:** ноды, которые описывают свои выходы (например, Rigstools), получают короткий
  заголовок и цветные строки о текущем значении; API для авторов нод (`getStyledOutputTooltip`).
- Подсказка с описанием ноды скрыта, пока перетаскивается нода, группа или холст.
- Значки версии и даты релиза в README.

## [1.0.0] — 2026-10-29
Первая публичная версия.
- Раздельные цвета шапки и тела нод и групп, диалог цветов, кисть формата, правила раскраски и файлы тем,
  копирование / вставка цветов (по желанию).
- Раскладка: выравнивание, ряд / столбец, одинаковый размер, подгонка группы по нодам — всё по клеткам; стрелки двигают
  выделение.
- Направляющие и магнит интервалов.
- Интерфейс на русском и английском.
